## Реальный зашифрованный UDP GETCONF — PASS

Использован **зафиксированный upstream legacy WIRE-2 тестовый GETCONF-пакет** из официального shared/wire_protocol.rs. Это тест совместимости формата, **не полноценная современная клиентская сессия**.
- Новый ARM64 сервер создал SRTP-сессию по UDP, принял зашифрованный GETCONF.
- Получен реальный UDP ответ, HMAC-SHA1/80 проверен криптографически с ключом HKDF CSQTT-WRAP-v1, ciphertext расшифрован AES-128-CTR.
- Полезная нагрузка после аутентификации: TUNCONF:10.67.69.2:77.88.8.8,77.88.8.1:46000:stream-v1:workers=27.
- Это подтверждает совместимость legacy GETCONF, выдачу виртуального адреса, серверное шифрование/аутентификацию управляющего ответа и локальный UDP-путь.
